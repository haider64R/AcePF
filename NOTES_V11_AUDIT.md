# AcePF Notes V1.1 coverage audit

The canonical taxonomy in `src/content/taxonomy.js` contains 152 records: ten category records, their grouping nodes, and the leaf concepts below. The ten Notes guides are sorted by the category records' `order`. This audit maps each group and its leaves to teaching content. A concept listed as **direct** has a focused rule, trace, or example; **grouped** means it is taught inside the named guide's broader explanation. All ten categories have a runnable Visualizer sample and links to related content selected from canonical topic tags. No new runnable samples were added in V1.1.

| Guide | Direct teaching | Grouped teaching and deliberate limits |
| --- | --- | --- |
| Fundamentals | Variables: declarations, initialization, assignment; types: integers, floating point, characters, booleans; input/output: `cin`, `cout`; conversions: implicit conversion and promotion | Constants and `const`, signed/unsigned distinctions, literal types, and initial-value errors are taught within storage and conversion. Real C++ widths remain implementation-dependent; Visualizer widths are a documented teaching model. |
| Operators | Arithmetic, division and modulo; simple/compound assignment; precedence and associativity; prefix/postfix; equality/ordering; logical and short-circuit; bitwise masking/shifts; ternary | Unary and mixed-type operations sit within expression tracing. Undefined unsequenced side effects are identified as invalid traces rather than assigned an invented output. |
| Selection | `if`, `if/else`, `else-if`, nested `if`; `switch` cases, break, fall-through | Nearest-unmatched-`if`, braces, default entry, and ternary branch choice are explained with actual paths. |
| Loops | `while` condition; `do-while` body-first; `for` phases and iterations; nested outer/inner loops; break/continue | Sentinel and off-by-one checks sit within the loop dry-run method. Continue's update/condition path and nearest-loop scope are tabulated. |
| Functions | Prototypes/definitions/void; calls, arguments, return values, call order; value/reference parameters; local/global/block scope and shadowing; recursion frames | Array and pointer parameters cross-link to Arrays/Pointers. Each recursive call is treated as a distinct frame. |
| Arrays | 1D initialization/indexing/traversal; character null terminator; 2D indexing and row-major storage; shared elements through function parameters | Partial initialization and bounds are taught with element-level state. No variable-length or more-than-2D array execution is claimed. |
| Pointers | Declaration, address-of, dereference, nullptr; aliasing; offsets/arrays; by-pointer parameters; const target/const pointer; arrays of pointers | Pointer arithmetic and array-of-pointer element tracing use arrows and cell identity. Examples do not imply physical address numbers. |
| Dynamic Memory | `new`, `new[]`, heap allocation; `delete`, `delete[]`, mismatch; dangling, leaks, use-after-free | Ownership is explained as a lifetime ledger. Invalid uses are errors/undefined in real C++, not normal values to memorize. |
| Project Structure | Header declarations, source definitions, signatures/prototypes, includes and multi-file execution | Include guards/`#pragma once` are explained conceptually. The Visualizer models a limited project subset, not a full preprocessor/linker. |
| File Handling | `ifstream`, `ofstream`, `fstream`; open/close; read/write/append; stream flags | File content and stream position/state are traced separately. Files are virtual in the Visualizer, not real disk access. |

The direct/grouped distinction is about where a concept is taught, not whether the runtime accepts every real-world C++ form. `SUPPORTED_CPP.md` remains the contract for executable examples. The expansion adds `details` and/or `worked-example` sections to every guide while retaining the original dry-run rules, traps, quick revision, and existing runnable programs. New illustrative snippets without a Visualizer link are teaching material; the 19 linked programs are the regression-checked executable set.
